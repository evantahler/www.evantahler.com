### Methods and apparatuses for combining and distributing user enhanced video/audio content {#us-11582507}

*US 11,582,507 · Granted February 14, 2023*

A program shows reference content, captures a video of the person watching it, and ties that video to a timecode in the reference content. It then marks which other people may view it and delivers the video so they can watch a composite of the user video and the reference content.

### Event state monitoring for multiple platforms associated with a user account {#us-10271005}

*US 10,271,005 · Granted April 23, 2019*

### System and method for an interactive device for use with a media device {#us-9522341}

*US 9,522,341 · Granted December 20, 2016 · Continuation of US 8,548,613*

### Method and system for pairing a medium to a user account {#us-9065870}

*US 9,065,870 · Granted June 23, 2015 · Continuation of US 8,781,115*

A media player reads an identifier from a medium and an identifier from its own memory, sends both to a server, and receives a key that ties them together. A computer can then send that key with a user account so the server can pair the account with the medium. The player and the computer both reach the server over the Internet.

- [US 9,065,870 on Google Patents](https://patents.google.com/patent/US9065870B2)
