# Patents

![patents](/images/patents.png)

I'm an inventor on ten granted United States patents. They are listed newest first. Each one includes the grant date, a short summary of the abstract, a link to the Google Patents record, and the drawing from the front page.

## Granted patents

<div class="patent">
<img class="patent-image" src="/images/patents/us10271005.png" alt="Front-page drawing for US 10,271,005" />
<div class="patent-body">

### Event state monitoring for multiple platforms associated with a user account

*US 10,271,005 · Granted April 23, 2019*

The patent describes monitoring the state of events across platforms tied to a user account, then sending event information suited to an electronic device so the user of that account can see it. The user can submit inputs about those events on the device, and the inputs are sent on to the platforms.

- [Google Patents](https://patents.google.com/patent/US10271005B2)

</div>
</div>

<div class="patent">
<img class="patent-image" src="/images/patents/us9522341.png" alt="Front-page drawing for US 9,522,341" />
<div class="patent-body">

### System and method for an interactive device for use with a media device

*US 9,522,341 · Granted December 20, 2016*

An interactive device communicates with a server that stores the current state of a media device while media is playing, then picks an action for that state and carries it out on its own hardware. The device can work on its own, or together with other interactive devices connected to the same server.

- [Google Patents](https://patents.google.com/patent/US9522341B2)

</div>
</div>

<div class="patent">

<div class="patent-body">

### System and method for providing a peripheral control interface for extending media device functions

*US 9,247,007 · Granted January 26, 2016*

A media device that already has its own functions connects to a network, finds a server, and obtains a peripheral control interface for a peripheral device. Commands sent through that interface make the peripheral do something the media device cannot do by itself.

- [Google Patents](https://patents.google.com/patent/US9247007B2)

</div>
</div>

<div class="patent">
<img class="patent-image" src="/images/patents/us9077858.png" alt="Front-page drawing for US 9,077,858" />
<div class="patent-body">

### Media playback system and method for monitoring usage of media contents

*US 9,077,858 · Granted July 7, 2015*

A media playback system keeps an analytic log for each piece of media, records events about how that media is used, and stores those events in the log. When a network connection is available, it sends the log to a remote server.

- [Google Patents](https://patents.google.com/patent/US9077858B2)

</div>
</div>

<div class="patent">
<img class="patent-image" src="/images/patents/us9065870.png" alt="Front-page drawing for US 9,065,870" />
<div class="patent-body">

### Method and system for pairing a medium to a user account

*US 9,065,870 · Granted June 23, 2015*

A media player reads an identifier from a medium and an identifier from its own memory, sends both to a server, and receives a key that ties them together. A computer can then send that key with a user account so the server can pair the account with the medium. The player and the computer both reach the server over the Internet.

- [Google Patents](https://patents.google.com/patent/US9065870B2)

</div>
</div>

### Method and system for pairing a medium to a user account

*US 8,781,115 · Granted July 15, 2014*

A media player reads identifiers from a medium and from its own memory, sends them to a server, and gets back a key associated with both. After the player provides that key to a user, a computer can send the key and a user account to the server so the account is paired with the medium.

- [Google Patents](https://patents.google.com/patent/US8781115B2)

</div>
</div>

### System and method for dynamic video placement on a display

*US 8,693,846 · Granted April 8, 2014*

A video playback device stores several video streams, each associated with different display coordinates. It takes a requested position on the screen, selects the matching stream, and plays that stream so the video appears in the chosen place.
